1. НАЗВАНИЕ ПРОЕКТА
--------------------------------------------------------------------------------

Decentralized Auction & Settlement Platform on Solana

Рабочее название: SolAuction (или любое другое по желанию)


--------------------------------------------------------------------------------
2. ELEVATOR PITCH (30 секунд)
--------------------------------------------------------------------------------

Децентрализованная аукционная платформа на Solana, где пользователи
взаимодействуют через кошельки, делают ставки, оплачивают в SOL
и проходят прозрачный цикл сделки от ставки до подтверждения
получения товара или услуги. Без банков, без посредников,
без централизованных аккаунтов.


--------------------------------------------------------------------------------
3. ПРОБЛЕМА
--------------------------------------------------------------------------------

Существующие аукционные платформы (eBay, OLX, Auction.com):

- Централизованы: платформа контролирует деньги, правила и данные
- Требуют традиционную платёжную инфраструктуру (банки, карты)
- Берут высокие комиссии как посредник
- Пользователь не контролирует свои средства до момента вывода
- Нет прозрачности: правила могут меняться платформой в любой момент
- Нет криптографической верификации действий участников
- Зависимость от юрисдикции и банковской системы


--------------------------------------------------------------------------------
4. РЕШЕНИЕ
--------------------------------------------------------------------------------

Платформа, где:

- Identity = кошелёк (Phantom, Solflare)
  Нет регистрации, нет email, нет пароля.
  Подключил кошелёк — ты участник.

- Ставки подтверждаются криптографической подписью
  Каждая ставка подписана приватным ключом владельца кошелька.
  Подделать невозможно.

- Оплата в SOL напрямую
  Победитель отправляет SOL продавцу.
  Платёж верифицируется через Solana RPC.
  Без банков, без карт, без эквайринга.

- Прозрачный lifecycle сделки
  Каждый этап (ставка → победа → оплата → отправка → получение)
  отслеживается и подтверждается участниками.

- Типы лотов
  Физические товары (электроника, вещи)
  Услуги (дизайн, разработка, консультации)
  Знания (курсы, менторство, доступ к информации)

6. TECH STACK
--------------------------------------------------------------------------------

Frontend:
  - Next.js (App Router)
  - TypeScript
  - Solana Wallet Adapter (@solana/wallet-adapter)
  - TanStack Query (data fetching)
  - Tailwind CSS (styling)

Backend:
  - Python 3.11+
  - FastAPI
  - SQLAlchemy (ORM)
  - Alembic (migrations)
  - PostgreSQL
  - solana-py / solders (Solana SDK)

Blockchain:
  - Solana (devnet для демо, mainnet для продакшена)
  - SOL как основная валюта расчётов
  - Solana RPC для верификации транзакций

Infrastructure:
  - Docker / Docker Compose
  - Nginx (reverse proxy)


--------------------------------------------------------------------------------
7. ФУНКЦИОНАЛЬНЫЕ МОДУЛИ
--------------------------------------------------------------------------------

Модуль 1: Wallet Authentication
  - Пользователь подключает Solana-кошелёк
  - Backend генерирует nonce
  - Кошелёк подписывает nonce
  - Backend верифицирует подпись
  - Сессия создаётся
  - Никаких паролей, email, регистрации

Модуль 2: Auction Management
  - Создание аукциона (название, описание, тип лота, дедлайн, стартовая цена)
  - Просмотр списка аукционов
  - Фильтрация по типу лота (товар / услуга / знания)
  - Карточка аукциона с историей ставок

Модуль 3: Bidding Engine
  - Размещение ставки
  - Ставка подписывается кошельком
  - Валидация: ставка > текущая лучшая
  - Валидация: аукцион ещё активен
  - Определение лидирующей ставки в реальном времени
